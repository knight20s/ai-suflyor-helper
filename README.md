# Suflyor

Окно поверх всех окон. Слушает звук из наушников (всё, что играет в системе), распознаёт речь собеседника локально через Whisper и сам вводит текст в Claude Code, который запущен во встроенном терминале в стиле VS Code.

Claude не принимает звук (ни API, ни Claude Code), поэтому речь в текст переводит Whisper прямо на этом компьютере. Никаких ключей и сторонних сервисов, в Claude уходит только готовый текст.

## Что нужно

- Windows 10/11
- Node.js 18 или новее (https://nodejs.org)
- Claude Code, установленный и залогиненный под своим аккаунтом: команда `claude` должна запускаться в PowerShell
- около 300 МБ места под Whisper и модель

## Установка

Проще всего через установщик:

1. Открой раздел **Releases** справа на странице репозитория и скачай `Suflyor-Setup-<версия>.exe`.
2. Запусти его. Установщик не подписан, поэтому Windows может показать «Windows защитила ваш компьютер»: нажми **Подробнее** → **Выполнить в любом случае**.
3. Выбери папку и дождись конца установки. На рабочем столе и в меню «Пуск» появится ярлык «Suflyor».

Установленная программа хранит настройки, Whisper и рабочую папку Claude в `%APPDATA%\Suflyor`. Удаляется через «Параметры → Приложения», папка с настройками при этом остаётся, её можно удалить руками.

Можно и без установки, из исходников: нажми **Code** → **Download ZIP**, распакуй в папку без кириллицы и пробелов в пути, например `C:\suflyor`, и запускай `start.bat`.

## Запуск

1. Ярлык «Suflyor» или, если запускаешь из исходников, двойной клик по `start.bat`. При первом запуске поставятся зависимости, это минута-две.
2. Программа сама скачает Whisper с GitHub и модель (около 200 МБ), прогресс видно в полосе статуса. Это один раз, дальше всё работает офлайн.

Дальше всё само: собеседник говорит, фраза появляется в полосе сверху, вопрос улетает в Claude, ответ печатается в терминале.

## Кнопки

- микрофон - слушать / пауза
- стрелка вниз - скачать чат сессии: вопросы собеседника и ответы Claude с временем, в текстовый файл (по умолчанию в «Загрузки»)
- пин - закрепить окно на месте, чтобы случайно не сдвинуть. Поверх всех окон оно остаётся всегда
- шестерёнка - настройки

## Режимы отправки

Переключаются кнопкой в полосе статуса или в настройках.

- **авто: вопросы** - обычные фразы копятся как контекст, как только прозвучал вопрос, всё накопленное уходит в Claude одним сообщением
- **авто: всё** - каждая фраза уходит сразу
- **вручную** - копится, отправляешь сам кнопкой «отправить» в полосе статуса

## Настройки

Всё лежит в `config.json` рядом с программой, его можно править руками. Самое полезное:

- **Модель Whisper**: по умолчанию `small` в сжатом виде, это баланс скорости и качества. Если распознаёт медленно, ставь `base`. Если комп мощный и хочется точнее, `medium` или `large-v3-turbo`. Новая модель докачается сама.
- **Потоки процессора**: 0 значит авто. Можно поднять, если ядер много.
- **Источник**: «Системный звук» ловит то, что слышно в наушниках. Можно выбрать микрофон, если собеседник сидит рядом.
- **Пауза конца фразы**: сколько тишины считать концом реплики. Меньше - быстрее, но чаще режет фразы.
- **Чувствительность**: подними, если тихий голос не ловится.
- **Скрывать окно в демонстрации экрана**: ты окно видишь, а в Discord, Zoom, OBS и на записи экрана на его месте пусто. Работает на Windows 10 версии 2004 и новее.
- **Аргументы Claude**: по умолчанию `--model haiku` ради скорости, поставь `--model sonnet`, если нужны ответы умнее. Флаг `--permission-mode dontAsk` значит, что Claude никогда не останавливается с вопросом «разрешить?»: всё, что не разрешено заранее, он молча не делает.
- **Системный промпт**: как Claude должен отвечать. После сохранения Claude перезапустится сам.

## Если что-то не так

- «не удалось захватить звук» - проверь, что звук реально идёт через устройство по умолчанию в Windows, и нажми кнопку микрофона ещё раз.
- В терминале «claude не является командой» - укажи в настройках полный путь, например `C:\Users\<имя>\AppData\Roaming\npm\claude.cmd`.
- Висит «качаю Whisper» или ошибка загрузки - проверь интернет, перезапусти программу. Недокачанные файлы удаляются сами.
- «whisper-server закрылся» - чаще всего его съел антивирус. Добавь папку `whisper` в исключения и перезапусти.
- Распознаёт медленно - выбери модель `base` или увеличь число потоков.
- Есть свой Whisper-сервер - впиши его адрес в `whisperUrl` в `config.json`, тогда локальный качаться не будет.
- Закрыл Claude через `/exit` - нажми Enter в терминале, он перезапустится.

## Сборка установщика

На Windows в папке с исходниками:

```
npm install
npm run dist
```

Готовый `Suflyor-Setup-<версия>.exe` появится в папке `dist`.

## Где что хранится

Все настройки лежат в `config.json`, Whisper и модель в папке `whisper`: у версии из исходников рядом с программой, у установленной в `%APPDATA%\Suflyor`. Claude Code работает в папке `workspace`, и программа сама отмечает её доверенной в `~/.claude.json` (флаг `hasTrustDialogAccepted`), чтобы не всплывал вопрос «Do you trust the files in this folder?». Перед первой правкой рядом сохраняется копия `.claude.json.suflyor-backup`. Ни то, ни другое в репозиторий не попадает (см. `.gitignore`). Чтобы удалить программу, просто удали папку.
